# CV — Frontend Developer

Personal CV / portfolio site. Built with pure HTML + CSS — zero frameworks.

## Deploy

This repo is ready for GitHub Pages. To deploy:

1. Go to repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / `/` (root)
4. Save — it'll be live at `https://camperdhaouadi-lang.github.io/cvfront/`

Or point your custom domain at GitHub Pages for runsite deployment.
